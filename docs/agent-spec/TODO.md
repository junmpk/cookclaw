## 每日内测聊天分析方案

每日批处理 SHOULD 只分析已授权内部测试账号：

~~~mermaid
flowchart LR
    L[授权测试日志] --> D[去标识化/脱敏]
    D --> C[按会话重建上下文]
    C --> T[问题分类]
    T --> M[指标与代表样本]
    M --> H[人工复核]
    H --> B[进入 Issue/回归集]
~~~

建议问题分类：

- 意图误判；
- 候选追问被重新搜索；
- 记忆遗漏/串线/错误固化；
- RAG 不相关、漏召、忌口违规、换批重复；
- 回复机械、重复、过长、语言不一致；
- 工具失败无解释或无最终回复；
- 设备确认、授权、状态与实际不一致；
- 通道渲染或媒体发送问题。

每日报告保留：总会话数、有效测试数、各类问题率、P0 样本、回归状态和新发现。原始账号、手机号、群号、设备 ID、消息 ID和图片链接必须脱敏。

禁止让分析任务直接修改 Prompt、自动发布规则或基于单个负面样本自我优化。正确闭环是：聚类 → 人工复核 → 定义期望行为 → 加回归测试 → 小流量验证 → 发布。
